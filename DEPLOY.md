# Развёртывание демо-контура

Схема PostgreSQL для этого приложения хранится в `supabase/schema.sql`, а синтетические записи — в `supabase/seed_demo.sql`. В подключённом проекте Supabase уже создана схема и загружена демо-наборка: 14 групп и по 28 записей с именами `Демо-студент NN`. Реальный реестр студентов в облако не переносился.

## Render + Supabase

1. Откройте Render и выберите **New → Blueprint**. Подключите GitHub и репозиторий `ANSTAPABAL/fiz-smtu`; Render обнаружит `render.yaml` в корне.
2. При создании сервиса задайте `DATABASE_URL` из **Supabase → Connect → Session pooler**. Нужна строка подключения в режиме **Session** (порт обычно `5432`): shared pooler поддерживает IPv4, тогда как прямое соединение бесплатного Supabase доступно по IPv6. Не публикуйте эту строку и не добавляйте её в Git.
3. Для `APP_PASSWORD` задайте отдельный длинный пароль, который будете сообщать преподавателям. Логин демо-контура — `fizruk`. `SESSION_SECRET` Render сгенерирует автоматически.
4. Нажмите **Apply** и дождитесь успешного первого deploy. Health check проверяет запуск веб-сервера; после deploy откройте выданный Render URL и проверьте вход, выбор группы, отметку посещаемости и экспорт.

Приложение сохраняет изменения сразу в Supabase PostgreSQL. В таблицах включён RLS, а роли `anon` и `authenticated` не имеют прямых прав на чтение; веб-сервер обращается к PostgreSQL только через секретный `DATABASE_URL`. Не выдавайте publishable/service-role ключи преподавателям.

## Ограничения бесплатного MVP

- Render Free усыпляет веб-сервис после 15 минут без входящих запросов; первый запрос после сна может ждать запуск. Его файловая система временная, поэтому локальный `fkis.db` для облачного хранения не используется. См. [ограничения Render Free](https://render.com/docs/free).
- Бесплатный Supabase может приостановить проект после недели низкой активности; резервные копии для бесплатного плана не включены. См. [условия бесплатного плана](https://supabase.com/pricing) и [автоматическую приостановку](https://supabase.com/docs/guides/platform/free-project-pausing).
- Сейчас задан один общий вход преподавателя, а не отдельные аккаунты и роли. Это демонстрация/MVP, не утверждённая производственная система.
- Демо-база содержит только синтетические ФИО. Локальный `fkis.db` включает реальные сведения, в том числе группы здоровья и идентификаторы студентов; переносить его в стороннее облако можно только после согласования с университетом о допустимом хостинге и обработке данных.

## Локальный режим

Без `DATABASE_URL` приложение продолжает использовать игнорируемый Git файл `fkis.db`, как раньше. Для запуска достаточно `start.bat`.
