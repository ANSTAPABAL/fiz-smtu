# Развёртывание ФКиС

Приложение рассчитано на Vercel Functions и PostgreSQL, заданный через `DATABASE_URL`. Не загружайте `fkis.db` в Git: он игнорируется и может содержать персональные данные. Перед подключением реестра студентов к внешнему облаку университет должен согласовать размещение и обработку этих данных.

## Настройки Vercel

В **Project → Settings → Environment Variables** задайте для Production:

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Приватная строка подключения PostgreSQL (Neon/Supabase) |
| `APP_USERNAME`, `APP_PASSWORD` | Отдельные логин и пароль преподавателя |
| `ARMADA_USERNAME`, `ARMADA_PASSWORD` | Учётная запись сотрудника ССК «Армада» |
| `EXECUTOR_USERNAME`, `EXECUTOR_PASSWORD` | Учётная запись ответственного исполнителя |
| `SESSION_SECRET` | Длинный случайный секрет для подписания сессий |

После изменения переменных нужен новый deploy. Для отправки писем студентам дополнительно задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USERNAME` и `SMTP_PASSWORD`. Без SMTP решение по заявке всё равно отображается в личном кабинете студента, но письмо не отправляется.

Создайте структуру PostgreSQL по `supabase/schema.sql`, затем загрузите согласованный roster через `import_rosters.py` или подключите источник ИСУ. Функция запуска проверяет наличие основных таблиц и применяет недостающие поля; демо-переключение ролей на production отключено. Для учащихся работает самостоятельная регистрация с подтверждением заявки ответственным исполнителем.

## Что проверить после deploy

Войдите отдельно под каждой ролью и проверьте доступные ей разделы. Проведите тестовую заявку студента, её подтверждение и возврат с комментарием; проверьте два типа занятия в один день, сохранение оценок, журнал и Excel-экспорт. Не используйте реальные персональные данные до согласования университетом облачного размещения.

## Локальный режим

`start.bat` запускает приложение на `http://127.0.0.1:4174`. Без `DATABASE_URL` используется локальный `fkis.db`; переключение ролей в этом режиме предназначено только для демонстрации. Не используйте демонстрационный режим для доступа к реальным данным из недоверенной сети.

## Известный незавершённый пункт

Автоматическая оценка физической подготовленности не рассчитывает баллы без официальной таблицы нормативов кафедры. Не задавайте пороги вручную: нужны нормативы по упражнениям и правила их выбора (в частности, по полу и возрасту).
